# Conservative-Apple-News-Channels
Do you have Apple News+? Are you tired of the radical left-wing slop Apple News feeds you every day? This repository lists all of the conservative/right-leaning news channels and magazines I have been able to find on Apple news, so you can see real, TRUTHFUL news.

In my extensive Apple News searches that utilized the help of AI, I've found a total of 23 reliably right-leaning channels and magazines, plus 5 channels that lean closer to the center but still regularly post center-right or right-leaning stories. If anyone else knows of any other conservative channels on Apple news, please let me know by opening an issue, so I can add it to the list!
